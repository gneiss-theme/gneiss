---
title: Obsidian
description: Install Gneiss's Obsidian theme.
---

Gneiss for Obsidian is a theme, dark only, that sets Obsidian's grays,
accent and colors from Gneiss's palette. Headings and links are `gneiss8`,
code uses the same colors as Gneiss's editor ports, and callouts keep
their meaning: blue for notes, yellow for warnings, red for errors. Where
Obsidian tints a background with a color, such as the selected file, a tag
or a callout, Gneiss uses a neutral gray, and callouts are edged in their
color instead.

## Install

Gneiss is in Obsidian's theme directory. In **Settings → Appearance**,
choose **Manage** next to **Themes**, search for **Gneiss**, and choose
**Install and use**. Then set **Base color scheme** to **Dark**.

### By hand

To install it without the directory, put its two files in your vault's
themes folder, from the vault's folder:

```sh
mkdir -p .obsidian/themes/Gneiss
for file in theme.css manifest.json; do
  curl -fLo ".obsidian/themes/Gneiss/$file" \
    "https://raw.githubusercontent.com/gneiss-theme/gneiss/main/dist/obsidian/$file"
done
```

Then, in **Settings → Appearance**, set **Base color scheme** to **Dark**
and choose **Gneiss** under **Themes**.

## With Nix

The flake's `obsidian` package is the theme's folder, with `theme.css` and
`manifest.json`, to copy to a vault's `.obsidian/themes/Gneiss/`.
[Nix](/apps/nix/) sets up the `gneiss` input.
