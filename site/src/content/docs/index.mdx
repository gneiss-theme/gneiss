Gneiss keeps Nord's syntax and status colors, which are distinct enough to
tell apart at a glance without anything shouting. It swaps Nord's blue-gray
backgrounds for neutral grays with the same contrast steps between them, so
the result reads like Nord in a darker, quieter room.
